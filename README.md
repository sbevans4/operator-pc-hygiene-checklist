## Inspect checklist

Use this as a self-audit or as the outline you expect in a written findings report.

### Startup apps

- [ ] List apps that launch at login / boot
- [ ] Note which ones you actually use in the first hour of work
- [ ] Flag auto-updaters, chat, cloud sync, and helpers you did not intentionally install
- [ ] Do **not** disable anything yet — write the list first

### Storage and downloads

- [ ] Check free disk space on the system drive
- [ ] Review Downloads for large installers, ZIPs, and duplicates
- [ ] Note temp / cache locations you are willing to clear (and which you are not)
- [ ] Identify large media or project folders that belong on another drive or archive

### Browser

- [ ] List extensions; mark unknown or unused
- [ ] Note default search / homepage changes you did not set
- [ ] Review startup tabs and pinned apps that reopen every session
- [ ] Clear only what you approve after the written list — not a blind “reset browser”

### Installed apps

- [ ] Export or screenshot installed programs
- [ ] Mark trialware, OEM bloat, and apps you have not opened in 90+ days
- [ ] Keep tooling you depend on for work even if “heavy”
- [ ] Plan removals as an approve-list, not a bulk uninstall

## Approve-before-change rule

1. **Inspect** — gather the lists above (or receive them in a written report).
2. **Report** — every proposed disable/delete/move is written down first.
3. **Approve** — you say yes/no per item before anything changes.
4. **Change log** — keep a short record of what was approved and done.

No silent sweeps. No “the AI fixed it” without a paper trail.
